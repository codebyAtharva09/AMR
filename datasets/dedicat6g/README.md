# DEDICAT 6G smart-warehouse robot KPI logs

EU H2020 DEDICAT 6G project: telemetry logs of warehouse robots, as idle and operational CSVs.

Used for: the realistic ~12 s load/unload time in the sensitivity test (`docs/EXPERIMENT_RESULTS.md` §8e)
and for sanity-checking energy constants. It is **not** an input to the main benchmark.
